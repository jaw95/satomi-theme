# Satomi Nishikigoi — Shopify theme

Backup of the live theme for satominishikigoi.com, pulled straight from Shopify.

- **Theme:** "Satomi 2027 - live" (based on Dawn)
- **Pulled:** 31 October 2026
- `pages/` holds the HTML body of each Shopify page (the content pasted into the page editor), one file per page. These are not theme files — they live under Online Store > Pages in Shopify.
- Everything else is the theme exactly as it sits in Online Store > Themes.

The `satomi-*.liquid` files in `sections/` are the custom parts built for the store (wheels, blind auction, azukari, hall of fame, events, salt calculator, and so on).
